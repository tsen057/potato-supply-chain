# EU Potato Supply Chain — Economics & Data Analytics

A Python-based analytical framework for evaluating on-farm production economics across Europe's four largest potato markets: **France, Netherlands, Poland, and Germany**.

Built to demonstrate skills in agricultural supply chain analytics, open-data integration, and evidence-based decision support for the food industry.

---

## What This Project Does

This project answers three questions relevant to a global food company's European potato procurement strategy:

1. **Where is potato production most cost-efficient in Europe — and why?**
2. **What data sources exist to monitor this continuously, and where are the gaps?**
3. **Which regenerative agriculture practices offer the strongest economic and environmental return?**

The analysis covers input cost structures, profitability trends (2015–2023), data source evaluation, and regen agriculture opportunity sizing — all built on real, citable government data.

## Key Findings

### Cost Competitiveness (2021–2023 average)

| Country | Cost/tonne | Gross Margin/ha | Margin % | Avg Yield (t/ha) |
|---|---|---|---|---|
| 🇵🇱 Poland | **€71.7** | €2,397 | 51.8% | 28.9 |
| 🇩🇪 Germany | **€71.9** | €5,298 | 62.2% | 44.4 |
| 🇫🇷 France | €88.6 | €4,397 | 54.7% | 39.9 |
| 🇳🇱 Netherlands | €101.1 | **€5,481** | 54.0% | 44.1 |

- **Poland and Germany** are the most cost-efficient markets per tonne
- **Netherlands** has the highest gross margin per hectare despite the highest input costs, driven by superior yields and processing premiums
- The **2021–2022 European gas crisis** drove urea prices up ~170% (World Bank), pushing fertilizer costs 45–55% above 2019 levels — the single largest supply chain risk for growers

### Top Regenerative Agriculture Opportunities

| Practice | Est. Market Saving | Carbon Benefit | Payback |
|---|---|---|---|
| Precision fertilization | **€16.4M** | 77k tCO₂/yr | 4 yrs |
| Reduced tillage | €12.7M | 253k tCO₂/yr | 4 yrs |
| Integrated Pest Management | €11.6M | — | 4 yrs |
| Cover cropping | €9.7M | 173k tCO₂/yr | **3 yrs** |

*Estimates based on 30% adoption at high-applicability markets across FR/NL/PL/DE.*

### Key Data Gap

No single open-access source provides harmonised, annual input cost data across all four markets. Bridging **Eurostat production data** with **FADN microdata** (requires Commission NDA) is the critical analytical gap for ongoing procurement monitoring.

## Getting Started

### Prerequisites
- Python 3.9+
- pip

### Installation

```bash
git clone https://github.com/tsen057/eu-potato-supply-chain.git
cd eu-potato-supply-chain
pip install -r requirements.txt
```

### Option A — Jupyter Notebook (recommended)

```bash
jupyter notebook eu_potato_supply_chain_analysis.ipynb
```

Then `Kernel → Restart & Run All`. All 10 cells run end-to-end producing charts, tables, and insights inline.

### Option B — Python Scripts

```bash
# Full pipeline (tries live API fetch first, falls back to verified data)
python run_pipeline.py

# Skip live fetch, use verified data directly (works offline)
python run_pipeline.py --skip-fetch

# Run individual scripts
python scripts/01_process_data.py
python scripts/02_analyze.py
python scripts/03_dashboard.py
```

All outputs are saved to `outputs/`.

### Option C — Live API Fetch

To pull the latest data directly from government APIs:

```bash
python scripts/00_fetch_data.py
```

This hits the **Eurostat Statistics API** (`apro_cpsh1`, `apri_pi15_outa`) and **World Bank Commodity API** and overwrites the verified fallback files. Requires internet access — both APIs are free and open.

## Methodology

### Cost Analysis
Variable costs are modelled per hectare across 8 input categories (seed, fertilizer, pesticides, fuel/energy, labour, machinery, land rent, irrigation). Gross margin is:

```
Gross Margin (€/ha) = (Yield × Farmgate Price) − Total Variable Cost
```

Farmgate price is estimated by applying the Eurostat producer price index (2015=100) to country-level base prices derived from FADN benchmarks.

### Data Source Scoring
Each of the 15 evaluated sources is scored on three dimensions (scale 1–3):

```
Composite Score = Quality × 0.4 + Access × 0.3 + Relevance × 0.3
```

Sources scoring above 2.2 are classed as **Primary** for ongoing monitoring.

### Regenerative Agriculture Modelling
Market-level savings are estimated at **30% adoption** for high-applicability markets, **15%** for medium, and **5%** for low. Impact is scaled to the most recent harvested area (Eurostat 2023).
